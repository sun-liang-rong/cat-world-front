# UI 统一复核记录

日期：2026-10-11。客户端 `main`，覆盖代码创建的页面、共享按钮和弹窗；web 看板单独提交。service 无界面，本轮没有改动。目标是统一视觉与修正可见布局问题，不能据此声称真实玩家留存提高。

## 共享规范与修正

- 文字操作走 Theme：暖黄主按钮、奶油次按钮、灰奶油禁用态，24px 圆角、3px 描边、轻投影、棕色粗体、文字内边距 16px。
- 可点控件通过 ensureButtonControl 设置 SCALE / 0.93 和 88px 最小热区。图标、标签页和收藏卡保留现有语义素材；呼吸动画在内层节点运行。
- 主操作高 96px 以上。结算主操作 440×104，分享 440×88，视频与返回各 208×88，间距 24px。无视频时返回铺满同一宽度。
- 修正 Cocos 同节点 Sprite / Graphics 渲染冲突，替换底板使用独立 ActionSurface。共享文字 helper 防止长文案溢出。
- 小镇面板加高并重新排布标题、说明、阶段、建设格、条件、CTA、奖励；状态角标改为纯展示，避免其热区撞阶段卡。
- 猫详情使用内容滚动视口，上方 HUD 和底部 68px 区域保持清晰；文字与按钮不通过缩小整页来塞进短屏。
- 地图箭头根据上下边界定位；底部主题栏离 Home 条 68px。排行榜常驻卡与列表留出 16px，卡底避开 Home 条。
- 活动、小镇、相册、设置、商店的辅助字号提高；长 Toast 按可见宽度换行，最多 3 行。
- 玩法介绍更新首猫安家和技能充能说明，去掉旧版“缩短冷却”描述。

## 检查结果与范围

- Cocos Creator 3.8.8 自带 TypeScript 全客户端检查通过。
- 既有 GameScreen 流程测试通过：取消落地动画、快速入槽、空棋盘结算、复活道具、收集目标保护。
- Cocos 独立 web-mobile 构建输出可运行，最新源码正常首关完整点击流程通过。CLI 最后返回 36，日志同时记录构建 Finished / 脚本及资源任务成功；这是本机 CLI 的退出行为，不伪称退出码为 0。
- Vue TypeScript 检查与 Vite 生产构建通过，使用本机已安装 Node 22（默认 Node 16 不满足当前 Vite 运行要求）。
- 两个仓库 git diff --check 通过。没有安装独立 tsc，没有手改原工程生成目录、资源 meta 或改变玩法规则。
- 浏览器验收使用独立端口和样例副本；没有清空真实预览存档、上传正式包或部署服务。一次验收端口切换产生本地 analytics CORS 错误，已给本地假 API 加跨端口响应；不属于正式游戏 UI 错误。

真实微信胶囊、好友开放数据域、广告无填充/完播、异形屏和目标低端机仍属于发布前平台验收。少数稀有运营状态和建成庆祝本轮按共享组件及几何检查，没有声称每个状态都经历真人点击。截图和源码复核覆盖当前所有界面文件，但无法承诺未来动态内容或所有设备永远没有问题。
